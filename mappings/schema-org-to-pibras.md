# schema.org -> PIBRAS

schema.org é alvo de publicação web e SEO, não modelo canônico.

## Uso

- páginas públicas de imóveis;
- páginas de empreendimentos;
- dados estruturados para buscadores.

## Regra

`Listing` público + `ExposurePolicy` geram a projeção schema.org. Campos sensíveis nunca devem ser puxados diretamente de `Property` sem a política de exposição.
